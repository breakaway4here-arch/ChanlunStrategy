# 界面样式审查

外观变更与数据逻辑变更分开说明。开工前讲清配色、字体、卡片和布局的调整范围；发布前展示同一份数据的前后效果。功能测试通过不能代替视觉审查。

## 工具各自负责什么

| 工具 | 用途 | 边界 |
| --- | --- | --- |
| [Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines) | 检查排版、交互、键盘焦点和语义结构 | 仍需实际看页面 |
| [Playwright 截图比较](https://playwright.dev/docs/test-snapshots) | 对比已认可的截图基线，发现意外视觉变化 | 截图基线必须先经视觉审查，不能自动接受所有差异 |
| [axe-core](https://github.com/dequelabs/axe-core) | 检查对比度、标签、ARIA 和其他可访问性问题 | 自动检查无法判断所有视觉或可访问性问题 |

## 每次视觉变更的验收

1. 使用同一天、同一快照比较前后页面，保留正常列表、空池、缺价、证据异常和无 K 线场景。固定样本明确标注，不进入正式产物。
2. 查看 1440×900、1366×768、390×844：正文可读，样式一致，标签不挤压，关键信息优先；不要仅检查横向溢出。
3. 检查搜索、无匹配结果、研究来源、键盘切换、手机详情关闭及桌面图表恢复。重要异常始终可见，不能为了简洁隐藏证据问题。
4. 用 axe-core 分别检查桌面主界面和已打开的手机详情。人工核对 incomplete 项；隐藏内容不得保留重复的标题引用或过期图表。
5. 回归测试、源/发布资源字节及版本一致。纯视觉变更要求每个入口的完整 bootstrap 与发布前一致，包括派生投影，不只比较原始行情。
6. 发布后重新打开线上页面，核对实际资源版本、日期与交互，并保留发布记录。

## 大盘证据不可折叠（2026-09-08 用户明确要求）

默认“今日决策”必须直接显示大盘原始依据。六指数、正式情绪五项事实与分项得分、最近 20 日情绪曲线不得置于任何 details 或研究标签内。检查真实 DOM 的可见祖先，并滚动检查桌面与手机；不能以默认 open 的折叠面板替代。完整证据使用正常文档流，提供直接跳到选股结论的链接。

综合情绪与指数涨跌必须标明统计范围；正式情绪的涨跌停数从同一日期的正式合同读取，不能拿研究涨停池数量代替。缺失值显示 --，无效合同显示数据不足。PSY12 保留独立研究身份。空选结论分别解释正式主推与 H4，明确剩余候选为何不是正式买点。

上一次审查通过了布局和可访问性检查，却漏验了此阅读要求；原 spec 对“长证据链移到第二层”的规定已据此更正。

本次在 1440×900、1366×768、390×844 实看默认大盘、依据行、曲线、结论跳转及研究切换。DOM 确认无折叠祖先、仅一个情绪图表且无横向溢出。axe-core 4.13.0 桌面与手机均无确定违规；隐藏研究内容的对比度与标题顺序仍为需人工检查项，未把自动检查当成整体清晰度验收。1953 项回归通过；14 个 HTML 仅更新资源版本，其中 13 个报告的完整 bootstrap 比对一致。
