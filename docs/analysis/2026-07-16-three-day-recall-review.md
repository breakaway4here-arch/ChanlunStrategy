# 三日强股漏选复盘与优化结论

**复盘日期：** 2026-07-16  
**回测会话：** `019f649e-229a-7a31-80cb-c37d1511f3dc`  
**审计区间：** `2026-07-10 -> 07-13`、`07-13 -> 07-14`、`07-14 -> 07-15`

## 1. 结论

推送差的第一原因不是最终决策过严，而是强股在更早阶段已经丢失：

1. Top20 共 60 只，35 只没有进入 800 只召回池，占 58.3%。
2. 5 只被 ST、上市状态或流动性资格门排除，占 8.3%。
3. 进入召回池后，9 只没有匹配日线低位或趋势通道，占 15.0%。
4. 2 只止于 30 分钟确认，占 3.3%。
5. 1 只进入主池，8 只进入观察通道，合计展示覆盖 9/60，即 15.0%。

“全部显示不推荐（高位风险）”确实是语义 bug，但它主要影响展示和动作解释，不是这三日强股漏选的首要原因。原逻辑把位置距离缺失当成高位；现在已改为“暂不判断（位置信息不足）”，只有明确高位才输出“不推荐（高位风险）”。

- 腾讯日线源没有直接成交额，本次大量历史 `amount` 使用 `volume * close * 100` 代理值；资格审计可复现，但不等同于交易所原始成交额。

## 5. 阈值怎么放

### 5.1 召回容量

按完全相同的历史日线特征做容量回放：

| 总召回容量 | Top20 命中 | Top30 命中 |
| ---: | ---: | ---: |
| 800 | 20/60，33.3% | 25/90，27.8% |
| 1000 | 25/60，41.7% | 30/90，33.3% |
| 1200 | 30/60，50.0% | 36/90，40.0% |
| 1400 | 31/60，51.7% | 40/90，44.4% |
| 1600 | 32/60，53.3% | 41/90，45.6% |

拐点在 1200。800 增至 1200 有明显收益，继续加到 1400/1600 的边际收益已经较小，却会增加日线分析和 30 分钟目标数量。

最终策略：

- 题材 overlay 正常：基础 800 + overlay 最多 400，总量最多 1200。
- 题材 overlay 不可用：基础召回直接扩到 1200，配额为低位 525、趋势 525、中性 150。
- 暂不扩到 1400 或 1600；先完成 20 日 walk-forward。

### 5.2 量比

不能把所有观察量比从 1.2 一刀切降到 1.0。实测会使 07-14 全池观察从 177 膨胀到 349，噪声过大。

最终采用分层阈值：

- 趋势主通道条件量比仍为 1.3，不放宽。
- 弱结构近失观察仍为 1.2，不放宽。
- 只有已经满足强趋势结构、仅缺量比的样本，观察下限从 1.2 放到 1.0。
- 低位强启动量比仍为 1.5。降到 1.2 没救回三日 Top20 漏票，却每天额外增加 105-141 个候选。

优化后 Top20 主池+观察从 7/60 提高到 9/60，新增万邦医药和迪哲医药-U；全池观察数量分别只增加 7、3、9，前端仍只展示 Top5，因此不会让用户看不过来。

## 6. 后续优先级

1. 保持新召回策略为 shadow，积累至少 20 个交易日门前漏斗。
2. 补齐 500 根 30 分钟线，完成 5 折 walk-forward，验证 1200 容量和分层量比。
3. 补历史板块成分后单独评估 overlay 增量，不能用当前 `overlay_hit=0` 下结论。
4. 监控每日 30 分钟目标数、远程补齐量、观察候选总数和 Top5 稳定性。
5. 只有收益和尾部风险通过门禁后，才把 `RECALL_STRATEGY_MODE` 从 `shadow` 切到 `active`。
