# 14:45 完整选股观察版实施计划

**Goal:** 新增每日 14:45 固定行情截止的完整分池观察任务，仅通过现有个人微信渠道推送，供用户与盘后版连续对照。

**Architecture:** 新入口负责只读历史、严格截止分钟行情、冻结输入、完整主流程注入及独立出箱。盘后主流程默认行为不变；观察结果不写正式行情、账本、候选漏斗、绩效、Pages 或旧预跑状态。

**Tech Stack:** Python 3.9、现有选股函数、SQLite 只读连接、独立 JSON 归档、WxPusher、独立 launchd 有限时任务。

## 数据与行为合同

1. 截止为交易日北京时间 14:45:00；生成时间独立。当天 OHLC、量、额都截止于此，禁止以晚到实时报价回标 14:45。
2. 由有身份与单位证据的 15 分钟完整桶合成当天日线；当日应有 15 桶。30 分钟只使用两根完整 15 分钟合成的周期，最后为 14:30。只接受严格递增、无重复、完整且价基可验证的窗口。
3. 历史日线截止上一交易日；独立日历确定上一交易日，检查必要窗口中间缺日、非 final 和量额缺失。停牌无证据不得猜补；不补零、不改 final 标志冒充修复。
4. 分钟价基用已结束历史日对照认证，不借用当日 15:00 日线。原日线保留真实历史收盘，今天最后一根保持 `is_final=false`。
5. 完整主流程计算既有分池；不使用旧三池预跑冒充完整流程。来源、候选母集、资格筛除、采集失败、预算排除、检索选择分别计数。非必要且无法证明截止的新闻/外部情绪等显示不可用，不混入盘后信息。
6. 观察身份贯穿输入、结果、微信和归档。保留算法输出供比较，但不得产生正式可执行动作、正式推荐记录或混入原收益统计。
7. 同一日期输入冻结后不覆盖；恢复沿用该输入。发送出箱绑定输入/结果哈希；成功不重复发，发送结果未知不盲重试。
8. 独立任务 14:45 启动，采集与计算预算止于 14:58，发送止于 14:59。不足以证明覆盖时显示失败或明确缺口，不能称正常空池或完整结果。不得改变旧预跑时间合同。
