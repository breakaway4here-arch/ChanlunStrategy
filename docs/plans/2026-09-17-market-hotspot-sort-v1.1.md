## 2. 固定排序规则

### 2.1 行业默认：按涨停家数

以同日、同来源、身份可识别且有效归属于涨停快照的完整分组登记为依据，每行业按规范证券身份去重。不要用屏幕卡片数、`lianban`之和、系统池命中数作为涨停家数。

默认比较键：

```text
涨停家数（降序） → 最高有效连板数（降序） → 原分组顺序（稳定）
```

当最高连板字段缺失，只影响这一级比较及其展示，未知排在同级已知之后；不补0，不丢股票。无需重建行业数据模型。

提供一个“板块排序”选择框，三种方式足够：

| 模式 | 排序键 |
|---|---|
| 涨停家数（默认） | 家数降序 → 最高连板降序 → 原顺序 |
| 连板高度 | 最高连板降序 → 家数降序 → 原顺序 |
| 系统命中 | 本行业命中系统的不同股票数降序 → 家数降序 → 最高连板降序 → 原顺序 |

系统命中3只股票不等于命中3池。每股“命中N池”继续复用既有组件，不能把N相加当行业命中只数。

本批不要求“板块涨幅排序”。现有行业分类与 `sector_heat` 的宽板块并非逐组对应：本样本43个组中同名直接对应的只有通信设备。已有明确同源板块涨幅可以作为附加事实显示；其余留空。不得以本组涨停股平均涨幅冒充全行业涨幅，不为了新增排序补齐全市场关系。

### 2.2 组内股票默认：连板优先、首封较早优先

```text
有效连板数（降序） → 首次封板时间（升序） → 证券代码（稳定兜底）
```

字段从当前热点快照读取。缺连板或首封时间，保留卡片并在相应比较项中靠后，不为排序新发请求。时间按有效HH:MM或既有合法格式读取，不把非法文本当00:00。

示例：电力组先显示闽东电力6连板，再显示首板；通信设备先显示通鼎互联2连板。该规则只是查看顺序，不能给第一只自动冠以“龙头/最安全/推荐”称号。

### 2.3 排序作用域

- 仅作用于热点模块的只读副本；不原地 `sort()` 修改报告、统一候选、策略名次或默认图表ref。
- 原有行业与颜色标识稳定：排序不改变行业身份，不用新名次重新分配行业色。
- 不改变主推集合、正式评分、研究/正式身份、执行条件或每股池计数。
- 原帖的光通信/PCB等细题材不能凭常识替换现有行业分类；本批不做题材重新归类。

## 3. 分页与收纳：先统计、再排序，最后决定显示几项

固定流程：

```text
全部有效快照 → 原行业归组/去重 → 完整行业统计 → 行业及组内排序
→ 用户阅读筛选 → 显示前几组/组内前几只
```

### 3.1 地图默认

- 首屏默认展示前6个行业，每组最多6只；数量是显示设置，不是业务或发布门槛。
- 组内超过6只，用“查看本组全部N只”；行业超过6组，用“更多行业（余下N组）”。所有原对象必须仍能从展开或筛选到达。
- 不再先截全局30只然后让各组争抢名额。
- 本样本按新默认键前6组为通信设备、半导体、化学制品、元件、包装印刷、其他电子；完整家数6、5、5、4、4、4。首次显示28只是该样本自然结果，不硬凑30只。
- 单股行业不删除、不合并成伪造新行业，默认较后或收在更多行业中。

### 3.2 标题要说明总数、显示数和系统命中数

建议：

```text
#01 通信设备      涨停6家 · 最高2连板 · 系统命中1只
[组内股票卡片……]
```

有分页/筛选时补：`当前显示2/6只`。原“2只”不能继续兼作涨停总数。

部分来源仅显示“已取得涨停N家”，明确统计范围即可，不要求覆盖率100%才给出局部排行。

### 3.3 搜索、只看系统命中、清单模式

- 搜索、行业筛选、只看系统命中在完整有效集合上操作，不能只搜已经渲染的卡片。
- 默认“涨停家数”对应全快照市场统计，不因搜索一个名字或勾选“只看系统”而悄悄改成另一个统计口径；额外显示匹配数/当前显示数。切到“系统命中”模式才使用那项指标作为第一排序键。
- 无匹配的组可以暂时隐藏，但剩余组仍按所选指标排序；清空筛选能恢复完整可达名单。
- 详细清单使用同一排序后的分组，组内有序展开，再对证券去重。多题材关联保留，不能在全局总只数里重复计股。
- 清单可保留30条加载批次，但必须排序后再分页。地图与清单的完整集合一致，不强求两种布局首屏露出的数量一样。
- 扩展更多、切模式、开关详情不重置排序；“清空”只清筛选，另有需要才设置“恢复默认”。
