# K 线特殊信号车道设计

## 背景

决策工作台已经通过右侧价标车道解决现价、参考价和历史信号在最新 K 线附近叠压的问题，但当前前端把全部 `markPoint.label` 强制隐藏，只在图表上方保留一个弱提示。结果是红色图钉仍存在，却无法让用户直接辨认“趋势延续候选”“底背驰候选”“启动日”等真实信号；`chart_annotations.labels` 也未被消费，`ZG/ZD` 结构线被决策价标白名单过滤。

2026-08-28 正式线上数据证明这不是上游缺数：九只正式主推均有 `chart_annotations.markPoints`，其中八只是“趋势延续候选”，分众传媒是“底背驰候选”。问题发生在显示层。

## 已确认方案

用户于 2026-08-30 选择方案 B：保留去碰撞设计，增加独立信号车道和可辨识短标，不恢复原来全部文字直接压在 K 线上的做法。

视觉继续沿用工作台现有 Swiss 方向：中性白底、细分隔线、Yves Klein Blue 作为交互强调。差异化组件是位于图表工具栏下方的“信号车道”，它承载真实信号文字，不侵占价格坐标区。

## 显示合同

### 主图

1. 最新动作信号允许一个短标，短标由真实信号类型映射：
   - `趋势延续候选` → `趋势`
   - `底背驰候选`、`swing底背驰候选种子` → `底背驰`
   - `startup`、`启动日` → `启动`
   - 含 `确认` → `确认`
   - 未知类型使用经过长度约束的真实名称，不伪造类别。
2. 历史动作只显示小点或小图钉，不显示常驻文字；鼠标悬停或移动端点击时由 ECharts tooltip 展示完整名称、日期和价格。
3. 可视区每 40 根 K 线最多三个带文字标记；其中最新动作优先。
4. 最后五根 K 线继续不得被右侧价标覆盖。

### 独立信号车道

1. 展示最多三条真实信号，按 K 线索引从新到旧排序。
2. 每条包含短类型、完整名称、日期；存在接近过期、确认日或种子原因时显示真实状态摘要。
3. 车道不得输出内部原因码，不得创造第二个正式动作。
4. 无信号时不渲染空壳。
5. `chart_annotations.labels` 中的确认日、种子原因进入车道的补充信息，不能继续被静默丢弃。

### 图层

1. `决策位`：显示最多两个价标、最新动作短标和信号车道。
2. `结构`：显示动作点、`ZG/ZD` 结构线；结构线数值使用短标签或车道摘要，不进入右侧决策价标竞争。
3. `趋势`：仅在真实 `EMA5/EMA20` 或 `MA5/MA20` 序列存在时提供入口，不补造序列。
4. 图层互斥，切换不得改变任何信号的日期、价格或正式动作。

### 默认窗口与历史入口

1. 桌面端和移动端默认只展示最近 20 根 K 线，成交量与 MACD 使用同一时间窗口；底部缩放条仍可展开全部历史数据。
2. `docs/index.html`、`docs/compare/index.html` 和所有 `docs/YYYY-MM-DD/index.html` 共同引用固定路径的共享 JS/CSS，因此每次资产变化必须统一刷新 12 位 cache-bust 版本号。
3. 刷新历史入口时只允许替换 `report-v2.js/css?v=<version>`，不得重写历史 Bootstrap、日报 JSON、正式动作或审计字段。
4. 历史日报必须能消费自身已有的真实 `chart_annotations`；例如 2026-08-27 飞凯材料已有启动信号、成交量和 MACD，不得因旧缓存版本继续隐藏。
5. 自动发布只暂存与 `HEAD` 相比“除真实资源 query 外逐字节一致”的历史入口；已有正文改动、手工 query、删除或不可解码文件必须原样保留且不能被误提交。root/data/today/assets 固定正式发布目标若在运行前已 dirty，则正式任务 fail-closed；同日正式进程生成但因验证、固化或推送失败而待重试的产物，只能凭同一 HEAD 的 hash journal 放行，finalizer 改写后必须刷新 journal。
6. 为避免 journal 与代码基线错配，正式任务必须先只读 preflight，再同步远端并 prepare；有待发布脏产物时禁止自动快进到新 HEAD。该保护只管理 Git 发布来源，不参与选股、市场情绪、PSY12 或 14:47 三池计算。

## 数据流

1. `report_generator.py` 继续生成现有 `chart_annotations.markPoints/markLines/labels`，不改变正式报告和选股合同。
2. `report-v2.js` 将原始标注规范化为纯展示模型：动作点、结构线、右侧价标和信号车道。
3. 展示模型只读，不反向写入日报 JSON、账本、市场数据库或选股结果。
4. ECharts 主图消费动作点和结构线；DOM 信号车道消费同一份规范化结果，避免两套含义。

## 容错

- 坐标不完整、日期不在当前窗口、价格不是有限数值的标注不进入主图。
- 名称或日期缺失的标注不得生成误导性短标，但其他有效标注继续展示。
- `ZG/ZD` 缺一时只显示存在且有效的一条；两者都缺时“结构”图层仍可只显示动作点。
- 移动端宽度不足时车道纵向排列，不产生横向滚动。

## 验收

1. 自动化测试覆盖最新短标、历史点化、三条上限、`ZG/ZD` 恢复、补充标签消费和移动端无溢出样式。
2. 真实 2026-08-28 页面至少验证：
   - 上海石化显示“趋势”短标和“趋势延续候选 · 2026-08-28”。
   - 分众传媒显示“底背驰”短标和“底背驰候选 · 2026-08-21”。
3. 使用正式线上页面拍摄 1440×900、1366×768、390px 截图；人工确认价标不叠压、特殊信号可辨识、最后五根 K 线无遮挡、零横向溢出。
4. 正式日报 JSON、选股池、账本和市场数据库在仅发布前端资产时保持不变。
5. 自动化证明默认窗口为最近 20 根，并证明生成新日报时会统一刷新已有历史日报的 JS/CSS 版本且不改变其正文。
6. 在线回读 2026-08-27 历史日报，确认它与根页使用相同资产版本，并用真实 300398 数据截图验证“启动”信号车道、成交量和 MACD。
