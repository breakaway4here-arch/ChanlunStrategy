## U04 缺图与量能能力状态

- 次数：2 轮实现（首轮红测/最小实现/回归；第二轮按主审反馈补充混合单位/来源与过期/冲突说明）。
- 根因：图表始终建立价格、成交量、MACD 三个面板；成交量序列在单位、来源或长度不可信时虽被投影为空值，却仍留下大片空副图，状态也没有保留混合单位/来源、序列缺失、过期或冲突原因。
- 结果：`projectChartVolumes` 的逐行 `hands`、原单位 `hands/shares`、来源和长度校验保持不变。全量缺失时只保留价格和 MACD 面板，成交量系列保持对齐但隐藏，工具区用可展开状态说明单位、来源、序列和原因；部分量能保留真实 `null` 缺口。混合单位/来源不再取第一项冒充统一口径，过期/冲突摘要常驻。
- 数据缺口：当前快照没有可信成交量元数据时仍不会生成柱；前端不猜单位、不补来源、不填零。新增上游量能字段需由数据契约任务提供，本文不补数。

## U05 图表交互、图层和结构证据

- 次数：3 轮实现（首轮红测/最小实现/回归；第二轮按主审反馈补充快照身份与重挂载；第三轮接入 MA10 与 `chart_ma` 展示声明）。
- 根因：图层切换无条件销毁并重建 ECharts 实例，使用固定最近20根索引重置窗口；决策/结构/趋势互斥，缺少独立叠加和窗口工具；结构几何只接受价位线，没有日期边界/端点的可信投影。
- 结果：同股同快照优先复用实例并读取当前 `dataZoom`；重挂载前检查 ECharts 实例的 `getDom()` 与当前 `chartMount`，旧挂载已卸载或 DOM 已替换时保存窗口、销毁旧实例并在新挂载重建。同日不同快照使用包装行、`snapshot_id`、`payload_hash`、`phase`、`version` 及日期边界区分，按新数据重算窗口。保留决策/结构/趋势预设，可信关键位、结构和趋势可独立叠加；趋势序列逐项支持 EMA5、MA5、MA10、EMA20、MA20，若有 `chart_ma` 声明则展示来源、是否派生、算法、窗口、价基和截至时间，参数不互称且不进入决策。提供最近20根、最近60根、全部、定位信号、重置，窗口按真实日期长度计算。中枢浅色区域仅接受显式 ZG/ZD 与起止日期，笔/线段仅接受序列化端点，前端不重算缠论；切换快照会清掉旧标注。
- 数据缺口：现有输出若只有 ZG/ZD 没有起止日期，继续只画水平线；没有序列化笔/线段端点不画几何。均线只使用实际 `ema5/ema20/ma5/ma10/ma20` 序列，缺失时保持不可用提示。
- 第4轮主审收紧：拒绝无法证明相对当前图表窗口的整数 `start_idx/end_idx`，拒绝 `upper/lower` 普通区间和 `raw.pivots` 推断中枢；已有投影为 conflict/partial/missing 时不允许 raw fallback 绕过冲突。新增三类负例并保留显式日期 + `ZG/ZD` 正例。

## U09 手机图表排版

- 次数：1 轮实现（红测 → 最小实现 → 相关回归）。
- 根因：图层、状态与操作共用一行，按钮在窄屏可能逐字断开；移动端右侧价签空间固定；图表触控没有声明纵向页面滚动边界。
- 结果：工具区按预设、叠加、窗口工具和状态分行，按钮与复选项以44px为目标且保持整词；价签右侧空间按实际标签文本动态计算并合并近值标签保留全部真实价位；图表声明 `touch-action: pan-y` 与横向边界，不锁页面纵滚。
- 数据缺口：价位文本仍受真实标签数量与设备宽度约束；超过可读空间时继续使用合并标签和可展开状态，不能裁切或改价。手机抽屉关闭/重挂载时保存当前窗口，数据切换仍按身份清理旧图表。
