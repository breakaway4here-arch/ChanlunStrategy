# 推荐票证据展示综合优化设计

## 1. 文档状态

- 日期：2026-08-30
- 状态：用户已确认，进入实施计划与测试先行落地
- 适用页面：ChanlunStrategy 日报首页、推荐池、个股详情、研究验证页
- 本轮性质：展示与只读数据编排优化
- 明确边界：不修改选股策略、池身份、正式门槛、评分公式、排序结果、市场情绪正式权重、PSY12 转正状态、14:47 预跑逻辑或正式动作
- 用户目标：不压缩现有信息量，不考虑个人持仓；补齐有意义的指标及其解释，让推荐票更清晰、可比较、可复核，并提升对软件结论的信任

## 2. 核心结论

本轮不能靠继续调整颜色、卡片大小或缩短文字解决问题。当前页面的主要缺口是：

1. 推荐结果有动作，但缺少完整的证据链和价格位置说明。
2. 候选之间可以看到顺序，却难以理解为什么前一只优于后一只。
3. 日线与 30 分钟确认存在于数据中，但多数只以概括性句子展示。
4. 量价、资金、市场和板块证据没有在个股详情中形成统一结论。
5. 参考价已经存在，压力位、失效位和分级目标字段也有合同，但实际正式推荐中经常为空。
6. 强势启动、趋势延续、加速等能力已经存在，却没有形成清晰的“主升浪线索”展示。
7. 策略账本和记分牌已经支持历史收益、MFE、MAE 与样本门，但没有转化成个股可理解的回测提醒。
8. PSY12 的 10% 权重属于影子市场情绪公式，目前独立大卡会造成“第二套正式情绪”的误解。

因此，本轮采用“完整证据展示”方案：保留现有页面容量，以一只推荐票为中心，完整展示结论、价格、结构、周期、量价资金、市场板块、风险条件和历史验证；所有内容只消费现有正式产物或对现有数值做只读展示计算，不反向影响策略。

## 3. 不做的事项

本轮禁止以下变化：

- 不增删任何正式推荐票。
- 不改变 `decision_engine_v1` 的分数、门槛或结论。
- 不改变 `opportunity_score`、`view_rank` 或池内排序。
- 不把 PSY12 写入正式市场情绪、市场温度或决策门控。
- 不新增“主升浪选股策略”，不把主升浪线索变成第二个动作。
- 不创建新的目标价、吸筹价、筹码成本或止损算法。
- 不用固定涨幅机械生成目标价。
- 不为缺失的压力位、失效位、30 分钟数据或回测样本补默认值。
- 不把模拟记录描述成真实持仓或真实成交。
- 不增加个人持仓、总仓位或个人盈亏管理。
- 不将新闻、LLM 或研究材料放入 14:47 关键路径。

允许的只读展示计算仅包括：

- 已有两个价格之间的距离百分比。
- 已有压力位与现价之间的上行空间。
- 已有失效位与现价之间的下行空间。
- 当压力位和失效位均真实存在时，计算展示用风险收益比。
- 对现有字段做分组、排序说明、状态翻译和来源标注。

这些派生值不得写回正式报告、账本、数据库或策略输入。

## 5. 推荐池完整横向比较

在现有候选列表之外增加完整比较视图，不改变现有池或排序。比较表按当前 `view_rank` 顺序展示，不提供前端重新排序造成的第二套排名。

建议列：

| 字段 | 展示内容 | 数据边界 |
| --- | --- | --- |
| 顺序 | 当前池内顺序、`view_rank` | 不重新计算 |
| 股票 | 名称、代码、行业/板块 | 现有字段 |
| 正式动作 | 可上车、等回踩、仅观察等 | 只读正式合同 |
| 决策结果 | recommend / observe / reject 的用户文案 | 只读 `decision_engine_v1` |
| 决策分 | 总分及结构/位置/情绪分项 | 不改变门槛 |
| 排序证据 | 已有 `opportunity_score`、关键加减分原因 | 明确“只用于池内排序” |
| 信号 | 买点类型、信号日期、新鲜度 | 现有买点与信号字段 |
| 价格位置 | 现价、参考价、偏离百分比 | 只读计算 |
| 日线结构 | 趋势、中枢、均线状态 | 现有分析结果 |
| 30分钟 | 已确认项目、未确认项目、数据日期 | 不重新判定 |

| 板块资金 | 板块净流入、排名、状态 | 仅在来源可验证时展示 |
| 风险 | 追高、涨停、结构和数据风险 | 现有风险字段 |
| 数据状态 | 最后日期、来源、终局状态 | 现有 `data_status` |

### 5.1 决策分与排序分的展示合同

两者不得继续以两个没有解释的数字并排出现：

- “决策分”负责解释股票是否通过正式决策门控，展示结构、位置、情绪三个分项。
- “决策分”数值只接受 `decision_engine_v1.total_score`；`score`、
  `final_score`、`opportunity_score` 均不得作为后备值，缺失时明确显示未提供。
- “排序证据”负责解释已经进入当前池后为什么排在第几位，展示现有排序字段及加减分原因。
- 页面必须写明：排序靠前不等于决策门槛更高；正式动作仍以唯一正式合同为准。
- 不新增第三个综合分或未经校准的“成功概率”。

## 6. 个股详情八个完整模块

### 6.1 推荐结论

目标：第一部分完整回答“为什么进入这个池、当前正式结论是什么、结论适用于什么证据范围”。

展示：

- 股票名称、代码、行业、所属板块。
- 唯一正式动作与动作原因。
- 正式决策代码及决策分项。
- 当前池身份、池内顺序和排序证据。
- 信号类型、信号日期、信号新鲜度。
- 已声明的适用周期；未声明时显示“策略未声明统一周期”。
- 数据日期、数据源、是否终局、是否陈旧。

不得展示：

- 个人仓位或总仓位。
- 第二套策略动作。
- 没有样本校准的置信概率。

### 6.2 价格与关键位置

目标：回答“当前在哪里、参考位置在哪里、上方和下方有哪些真实结构位”。

展示：

- 现价。
- 正式 `reference_price`。
- 当前距参考价的百分比及状态：接近、适中、偏离；状态文案只能复用已有策略风险结论，不新增门槛。
- 中枢 ZG/ZD、平台高点、买点价格等已有结构位，并明确字段来源。
- 正式 `pressure_price`。
- 正式 `invalidation_price` 或已有 `stop_loss`。
- 已有 `trailing_targets` 分级目标。
- 当真实上下边界齐全时，展示上行空间、下行空间及展示用风险收益比。

空值规则：

- 没有压力位：显示“本期未形成可验证压力位”。
- 没有失效位：显示“本期未形成可验证失效位”。
- 没有目标：显示“本期未形成分级目标”，禁止固定加 5% 或 10%。
- 多个字段互相冲突：隐藏冲突值，进入证据审计并显示“关键价格存在冲突”。

### 6.3 日线结构

目标：把现有日线分析从概括文案变成可核对的结构证据。

展示：

- 趋势方向与当前结构阶段。
- 中枢数量、最近 ZG/ZD。
- 买点类型、买点价格、信号日期和原因。
- MA5、MA10、MA20、MA50 的当前值、相对关系和已有方向字段。
- 平台突破、中枢突破、回踩、背驰等现有信号。
- MACD 当前状态及已有背驰证据。
- 信号距今有效交易日数。
- 结构完整、结构近失、结构破坏等已有健康状态。

不使用一句“均线保持”代替实际数据；如果报告没有序列或当前值，则明确显示数据未提供。

### 6.4 30分钟确认

目标：回答“日线信号是否得到 30 分钟真实确认”。

展示：

- 30 分钟数据最后时间、K 线数量、是否补齐、是否陈旧。
- EMA5、EMA10 当前值及大小关系。
- EMA5、EMA10 的已有方向证据；没有方向字段时不从单点大小推断“维持良好”。
- 收盘价与 EMA5/EMA10 的关系。
- MACD DIF、DEA、柱体方向及连续性，前提是数据已序列化。
- 突破位最近若干根是否跌破。
- 回踩阶段量能是缩量、放量还是未知。
- 已满足的确认项、缺失的确认项和最终状态：确认、部分确认、未确认、数据不足。

页面必须把“EMA5 高于 EMA10”和“30 分钟走势健康”分开表达，前者不能自动替代后者。

### 6.5 量价与资金

目标：回答“上涨或回踩是否得到真实成交和资金证据支持”。

展示：

- 当日成交量、成交额、换手率（存在时）。
- 5 日和 20 日均量、当前量比。
- 已有量价标签：放量突破、缩量回踩、放量滞涨、量能不足等。
- `money20` 及其来源状态。
- 个股大单净流入、连续净流入天数，仅在现有正式数据源可验证时展示。
- 板块净流入、板块资金排名和层级去重状态。
- 个股成交强度与板块资金是否同向。

不得把成交量放大直接翻译成“主力吸筹”；不得把板块资金流入冒充个股资金流入。

### 6.6 市场与板块共振

目标：回答“市场、板块和个股是否处在同一方向”。

展示：

- 正式市场情绪分、标签和正式组件。
- 正式市场情绪只有在报告日期、版本、覆盖率、`insufficient=false`、
  五个组件及各自 `evidence.available` 一致时才可展示；合同残缺或冲突时
  fail-closed，不得仅凭一个 `score` 生成正式温度。
- 所属板块涨跌幅、上涨家数/总家数、涨停家数、资金净流入、市场排名。
- 个股在板块内的相对强弱字段；没有正式排名时不推算。
- 市场、板块、个股三层分别标记：支持、分歧、风险、未知。
- 同一板块同时存在正反证据时合并展示为“分歧”，不生成两张相互冲突的方向卡。

PSY12 只作为本模块中市场情绪的影子证据，具体见第 8 节。

### 6.7 风险与下一步

目标：让用户明确知道“下一步看什么、什么情况降低信心、什么情况结论失效”。

展示：

- 当前风险标签及真实原因。
- 下一确认条件。
- 继续保持条件。
- 等待回踩条件。
- 取消推荐或降级条件。
- 结构失效条件与价格位。
- 涨停、跳空、距参考价过远、放量长阴、数据陈旧等现有风险。
- 公告或事件风险仅在正式日报已有可验证证据时展示，不进入 14:47 预跑。

“暂无新增确认条件”不得作为常规默认结论。确实没有策略声明时，页面写“当前策略未声明下一确认条件”，并进入数据完整性提示。

### 6.8 历史验证与回测提醒

目标：回答“同一策略合同历史上表现怎样、当前结论有没有足够样本支撑”。

展示：

- 策略、版本、来源池、入场方式、目标周期和研究层级。
- 成熟样本数、活跃交易日数、覆盖月份。
- T+1、T+3、T+5 的中位收益、均值和上涨比例。
- 基准超额收益。
- MFE、MAE、最差不利波动。
- 样本起止日期和右删失数量。
- 当前股票若已有同合同跟踪记录，展示信号日期、规则入场价、跟踪状态和已成熟周期。

页面名称使用“策略模拟跟踪”或“回测提醒”，禁止使用“真实持仓中”。

样本门未满足时：

- 只展示采集进度和不足原因。
- 不显示胜率结论、收益排行或单一夸张收益。
- 不把某一笔历史收益当成策略可靠性证明。
- `entry_mode` 缺失时不生成模拟建仓价。

## 7. 四项参考能力的本轮落地方式

### 7.1 “吸筹价”改为“结构参考与成本证据”

本轮没有筹码分布或主力真实成本合同，禁止直接展示“吸筹价”。

本轮可展示：

- 正式参考价。
- 买点价格。
- 中枢 ZG/ZD。
- 平台突破位。
- 现有绝对位置分位。
- 已有成交额、量比和资金证据。

模块标题使用“结构参考与成本证据”。只有未来具备可靠筹码分布、成交密集区或大单资金成本数据并完成单独评审后，才讨论“成本密集区”或“疑似吸筹区”。

### 7.2 目标价改为“目标与压力位”

本轮只展示现有合同中的：

- `pressure_price`
- `trailing_targets`
- ZG、前高等结构位，但结构位必须按原名称展示，不能自动冒充正式目标。

所有价格同时展示来源、生成日期和有效状态。没有正式目标时保留真实空态。

### 7.3 主升浪改为“主升浪线索”

本轮不新增主升浪算法，只翻译现有信号来源：

| 现有证据 | 展示文案 |
| --- | --- |
| 强势启动候选 | 启动确认线索 |
| 趋势延续候选 | 趋势延续线索 |
| 加速池命中 | 加速线索 |
| 距参考位过远、涨幅过热 | 加速过热风险 |
| 结构破坏 | 主升线索失效 |
| 无对应证据 | 尚未形成主升浪线索 |

模块必须并列展示支持证据和反对证据，不把“线索”升级成正式动作或确定性预测。

### 7.4 回测操盘提醒改为“策略模拟跟踪”

本轮只读取已有推荐账本、结果成熟度和策略记分牌：

- 有合法 `entry_mode` 和同合同记录：展示模拟入场、成熟周期和当前状态。
- 只有汇总记分牌：展示策略级历史验证，不伪造个股买卖记录。
- 没有记录：显示“暂无同合同历史跟踪记录”。
- 页面可以显示目标或失效是否已触发，但只读取已有结果，不新增盘中监控任务或微信推送。

## 8. PSY12 展示归并

### 8.1 现状问题

PSY12 当前作为独立大卡出现，虽然文案注明“影子，不影响正式决策”，但视觉权重接近正式市场情绪，容易让用户误以为存在第二套正式市场判断。

### 8.2 新展示结构

移除独立同级大卡，将 PSY12 收入“市场情绪”卡的影子子面板：

```text
市场情绪 62 / 100 · 偏强                       正式
正式组件：广度 | 涨跌停生态 | 指数 | 成交额 | 趋势

PSY12 上涨持续性 50 · 6/12                    影子评测
加入 10% 后：62 · 偏强 · Δ0
未参与正式市场温度、选股门控或 14:47 动作
影子观察进度：X / 20 个有效评测日
[展开 12 日方向和影子权重]
```

必须区分：

- `6/12` 是当前 PSY12 窗口中的上涨日数。
- `X/20` 是独立的影子评测交易日进度。
- 达到 20 日也不自动转正，仍需新的设计和授权。

## 9. 图表展示

保留现有 K 线、成交量、MACD、最新短标签、历史信号点、独立信号车道和 ZG/ZD 结构层。

新增展示规则：

- 决策层：现价、参考价、真实失效位、真实压力/目标位。
- 结构层：ZG/ZD、买点与主升浪线索。
- 趋势层：只有真实均线序列存在时展示。

- 目标、压力、失效、参考使用不同线型和图例，不只依赖颜色区分。
- 缺失价格不画 0 值线。

## 10. 缺失、冲突与数据质量

统一使用以下展示语义：

- 没有正式推荐：本期未选出推荐票。
- 有推荐但字段缺失：明确指出缺少的证据，不把整只股票判为数据不可用。
- 30 分钟数据陈旧：显示最后时间和缺口，不复用历史确认冒充当日确认。
- 关键价格冲突：隐藏冲突字段并显示审计提示。
- 资金来源不完整：显示“资金证据不足”，不得写“主力流入”。
- 回测样本不足：只显示进度。
- PSY12 不可用：正式市场情绪照常显示，影子子面板显示真实原因。

页面中每个重要指标都应附带以下最小元数据之一：
