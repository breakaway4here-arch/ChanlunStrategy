# L1 研究名单网页展示

## 本批目标与边界

用户在 L1 日常研究旁路交付后追问“ 不展示吗 这个 ”，本批补上实际可见入口和自动发布。基线是实际运行目录与 `origin/main@9e8bfca`，实施树为 `codex/l1-display-20260917`。代码子 agent 沿用用户确认的 GPT-5.6 Sol / xhigh，主进程保持当前配置并独立验收。

复用日报已有“研究验证”，在其首部显示“L1 次日强势研究候选”。独立公开数据只投影已冻结的 research 名单及结果，不重新执行选股，不读写行情库，不更改 L1 排序。展示同日报告日期、算法版本、研究名次、来源、行业涨停家数、连板数、首封时间、风险和待确认条件；并列保留原看点顺序和重合情况。未到期、缺价、价基未核验、成交不确定分别显示，开盘到收盘只是价格路径。

正常日报发布成功后，现有可选研究 hook 继续产出本地结果，再在有界、独立失败的步骤发布 `docs/research/nextday/YYYY-MM-DD.json`。页面按本期日期读取；缺失、日期不符或输入不足只影响本模块，可局部重试。不借用最新一期填历史页面，也不替换已冻结股票。

影响 B02/B04/B06/B07/B09/B10 的展示和发布隔离；B01/B03/B05/B08 的生产行为不变。原主推、评分、正式准入、H4、右侧开关、通知、热点地图及既有局部降级保留。不增加新数据库、全市场候选或分钟预算，不重跑日报，不补历史。前端资源发布只更新资源及 HTML 引用版本，不改内嵌日报数据。

## 验收与发布

1. 白名单投影检查身份、顺序、日期与本地冻结记录一致；不公开配置、路径、堆栈和原始日报。
2. 独立发布检查远端同步、空暂存区、仅研究数据暂存及失败隔离；保留运行目录其他脏改动，推送失败保留待推送提交。
3. UI 检查同日正常名单、原看点不足五只、缺失/错误日期局部状态、所有未到期指标和历史页日期绑定；执行相关前端、日报、研究回归。
4. 主进程先以已冻结 2026-09-17 文件投影公开数据，再发布源码和静态资源；不得因 HTML 资源版本变化重新选股替换原研究名单。
5. 线上桌面和 390px 手机宽度实际打开“研究验证”，核验五只名单、原看点三只、排序依据和未到期状态。仅有本地测试或 HTTP 成功不称展示验收完成。

## 实际结果

- 主进程独立执行前端、热点、对照、主入口及资源发布 185 项回归，以及研究、结果、公开投影、临时 Git 发布、hook、日报和正式发布隔离 98 项回归，均通过；JS 语法和差异空白检查通过。
- 真实输入为已冻结 `2026-09-17`：候选 36、完整涨停快照 47、交集 13。公开投影保留 L1 原顺序：金杯汽车、克来机电、中晶科技、锡华科技、南华生物；B0 原顺序：多瑞医药、克来机电、芯原股份，仅克来机电重合。八条结果均未到期，没有伪造收益。
- 已检查公开 JSON 不含运行路径、原始来源证据、参考价或行情库溯源；输出字节确定，源冻结文件不改写。OC1 上涨门限保持包内 3%，CC1 保持 5%；一字日成交不确定独立保留。
- 旧热点测试曾混用 9/16 JSON 与动态首页（已为 9/17），原上线版本同样失败；仅将输入固定为 9/16 归档后原计数、排序断言通过。CSS 测试改为读取所有真实对应断点块，保留原图表、热点与研究布局保护；没有改热点算法或降低断言。
- 已同步 JS/CSS 发布副本，检查 18 个 HTML 入口去除资源版本后的内容逐字节不变；需要缓存更新的入口只改资源查询版本。不重新生成日报。
- 发布器使用单独 30 秒操作预算并保留收尾时间，不在 Git 写入中途被外层硬杀；CLI 原 60 秒预算保持。冻结冲突只在验证同日已有记录有效后继续投影，冲突状态仍记录。远端领先、已有暂存内容或研究路径有脏改动时跳过；失败不改变日报结果。
- 首发源码提交与运行目录更新、线上桌面及 390px 手机读回由主进程执行。未完成这三项前，本地通过不代表线上展示通过；本地部署与浏览器验收回执保存在本批任务证据中。
