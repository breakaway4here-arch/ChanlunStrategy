# 开盘啦两项非阻断接入

用户批准：独立展示题材/涨停原因；验证日线后做末位备用。不要因新增源限流影响原日报上线。沿用本会话主进程实现，不改正式策略、L1/B0、板块映射或既有发布门。

实现路径：
1. `chanlun/kaipanla.py`：HTTPS正常验签、无账号、原始响应按请求缓存；题材单次请求，无分页扩抓/无重试，失败返回独立空态。实际响应日期保留，前一日资料明确标注；不作为当日完整涨停池。日线只在既有三源均无有效结果时调用，整窗返回且复用既有仓库校验/缓存。网络调用串行、复用缓存，失败不递归重试。
2. `run.py`：日报末端增加可选字段，异常只略过该补充。`report_generator.py` 两个投影保留该字段，HTML生成独立折叠卡片，不给市场评分、正式排序或L1提供输入。无需修改共享JS/CSS或刷新全历史资源，无浏览器端取数。
3. `data_fetcher.py`：增加日线最后备用，不扩大原来源请求。日期/OHLCV/复权检查沿用安全边界，取不到保持原失败语义，不新增日报门槛。
4. 先失败测试，再实现；固定输入对照正式投影不变；接口失败、旧日期、恶意文本、缓存命中、原源成功不调用KPL、末位补源与分钟入口不受影响均覆盖。源码和发布资源核对后按本批授权交付，不重跑正式选股或通知。
