## 回收与发布流程

每批先检查实际 diff 对照需求，再检查代码质量、复现关键负例和相关回归；主进程不能只依赖 agent 报告。提交前同步最新 origin/main、确认祖先并重新回归。冲突由实现 agent 修正，主进程核对，不覆盖其他人的更改。

源码与生成资产通过既有受控流程同步。A 类逐入口完整 bootstrap hash 相等；B/C 类白名单之外相等。发布前记录源码、数据、账本、数据库保护证据；发布后读回真实根页/当期日期页/历史日期页与资源版本，三视口及关键交互验收。不得运行生产日报为 UI 刷新。

回滚使用本批逆向源码/资源改动并保留之后新增日报、数据和 outbox，不用旧快照覆盖新报告。任务结束关闭本任务启动的浏览器/临时进程并确认释放；不停止已有业务服务。
