# 主界面市场情绪卡布局优化设计

## 目标

解决主界面“市场情绪”卡在桌面端四列辅助决策网格中只有约四分之一宽、折线图又高又窄的问题。在不改变情绪计算、回测逻辑和其他业务口径的前提下，提高20交易日情绪走势的可读性。

## 已确认方案

- 辅助决策中心第一行保持四列栅格，但市场情绪卡占两列，板块资金卡占两列。
- 市场情绪卡内部采用左右布局：左侧约30%展示当前情绪、状态、构成分与证据覆盖；右侧约70%展示20交易日折线图。
- 折线图继续展示每日情绪、3日均线、转强/转弱标记和情绪区间背景，不修改数据及计算逻辑。
- 桌面端图表高度控制在约300px，整卡目标高度约360–420px，避免原先约800px的纵向占用。
- 1180px以下改为情绪卡独占整行；760px以下恢复为上下单列，指标在上、图表在下。
- 板块资金卡维持现有内容和两列宽度，不改资金计算。

## 页面结构

### 桌面端

辅助决策中心第一行：

1. 市场情绪：跨两列。
2. 板块资金：跨两列。

市场情绪卡内容：

- 左侧：情绪仪表、综合分、广度、指数、涨跌停生态、量能、趋势结构、证据覆盖。
- 右侧：20交易日情绪折线图。

其余涨停情绪、事件驱动、卖出提醒、策略回看和数据诊断保持现有顺序，避免扩大本次范围。

### 移动端

- 所有辅助卡保持单列。
- 情绪卡内部取消左右分栏，指标与图表上下排列。
- 图表宽度100%，高度约240px，不产生横向滚动。

## 数据与交互

- 不新增数据请求。
- 不改变 `market_sentiment` 和 `market_sentiment_history` 合同。
- 折叠、窗口缩放及手机抽屉场景继续调用 ECharts `resize()`。
- 数据缺失时沿用“暂无可复算的历史情绪证据”。

## 验收标准

- 1280px以上市场情绪卡与板块资金卡各占辅助决策中心一半宽度。
- 情绪折线图宽度明显大于高度，20个日期和转折标记可读。
- 1180px以下情绪卡独占整行，760px以下单列无横向溢出。
- 情绪计算、板块资金和其他辅助卡内容不变。
- 前端契约测试、全量Python测试和浏览器桌面/手机验收通过。
