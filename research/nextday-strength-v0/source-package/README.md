# 次日强势筛选实测与候选算法 v0
**这是已经执行过对照的研究包，不是自动覆盖主推的生产补丁。**

先读《研究结论.md》。核心结论：昨日涨停具有跨子段重复的次日强势关联；具体“行业涨停家数→连板→首封时间”的5只候选算法，近10日19/49次日≥5%，但更早6日仅3/30，且近期涨幅大多来自隔夜高开。未达到直接替换正式主推的证据水平。

## 文件
- `研究结论.md`：所有正面和反面结果、明确算法、采用范围。
- `scripts/nextday_candidates.py`：真正选出最多5只研究对象的纯读取函数，不读取未来结果。
- `scripts/reproduce_study.py`：复算10组比较，逐日固定选择后再读结果。
- `data/signal_features.jsonl.gz`：2,504条历史信号字段，不含未来收益。
- `data/outcome_paths.jsonl.gz`：相同日期×证券对应的后续价格路径，单独保存。
- `results/`：所有规则/子段结果、具体选择、开盘敏感性及计算核验。
- `study_plan_round1.json`、`study_plan_round2.json`：两轮探索范围，第二轮不是独立盲测。
- `provenance.json`、`MANIFEST.sha256`：数据来源与文件哈希。

## 使用
在解压根目录执行（Python 3.10+，标准库，无额外依赖）：
```bash
python scripts/reproduce_study.py --out ./recomputed_new
python scripts/nextday_candidates.py --date 2026-09-15 --out ./research_candidates_0915.json
```
输出目录/文件应使用尚不存在的新路径。不会联网，不写库，不调用生产主流程。日期在本包之外就明确提示，不自动补数。
样本截止2026-09-16收盘，不能据此查询9月17日实时行情。

## 边界
本包的“次日大涨”是相对信号日收盘≥5%，不是交易胜率。开盘到收盘只是走势诊断；费用、滑点、涨跌停成交及分时触发尚未模拟。历史归档存在重建/跨版本和重复股票，不假装有独立样本外证据。
不修改正式主推、H4、评分、阈值、右侧开关、通知、热点地图或日报发布门。不要求每日必须出5只，不因实验缺失让既有日报停止。
没有要求用户重复导库。需要产品集成时，仅在现有自然日报旁路写research结果；改正式策略须明确说明具体行为和结果，不借本包自动授权。

此包不是另一份改UI任务单，重点是一个可运行的具体筛选假设、已经跑出的表现及失效证据。
